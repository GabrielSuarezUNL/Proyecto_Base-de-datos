# Scripts SQL

Ejecutar los archivos en orden numérico:

- `01_ddl.sql`: creación de la base de datos y estructura de 13 tablas.
- `02_dml.sql`: inserción de datos de ejemplo.
- `03_consultas.sql`: cinco consultas SQL con su planteamiento en álgebra relacional.
- `04_verificacion.sql`: comprobación de tablas y registros.

Consulta la [guía de ejecución](../docs/guia-ejecucion.md) para más detalles.
