# Contenido de los scripts SQL

Los archivos SQL documentan la estructura, los datos y las consultas de la base de datos **La Huequita del Sabor**.

- `01_ddl.sql`: definición de la base de datos y creación de las 13 tablas.
- `02_dml.sql`: registros de ejemplo relacionados con las entidades del modelo.
- `03_consultas.sql`: cinco consultas con su expresión de álgebra relacional y su traducción a SQL.
- `04_verificacion.sql`: sentencias para consultar y visualizar la información de las tablas.

La descripción de cada tabla, los modelos y los ejemplos de álgebra relacional también se presentan en el archivo principal `README.md`.
